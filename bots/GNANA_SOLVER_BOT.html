Voice troubleshooting
  • Use a recent version of Chrome or Edge. Speech recognition is not supported in every browser.
  • Allow microphone permission for the browser/site and check that no other app is blocking the microphone.
  • Speech recognition may require internet access even though the numerical solver works offline.
  • If you opened this file directly, try opening it in Chrome. If recognition still fails, host the file on HTTPS or use typed input.
  • Read the recognized equation carefully and edit it before pressing Solve.

Numerical methods return an approximation. The solver also checks whether a simple rational root candidate (denominator ≤ 100) satisfies the original function to a strict residual tolerance; this is not a general symbolic exact-root engine. Bracketing methods require continuity for the usual root guarantee.

Equation-format help
  • Operators: + − * / ^ and parentheses. Implicit products such as 2x or 3(x+1) are accepted.
  • Constants: pi, e. Variable: x only.
  • Functions (all need parentheses): sin cos tan asin acos atan sinh cosh tanh exp log ln sqrt abs. Here log and ln are both the natural logarithm; log10 is also available.
  • Angles are in radians. A single "=" is allowed: x^2=5 is treated as x^2−5=0.
  • Examples: x^3-x-2=0, e^(-x)-x=0, cos(x)-x=0, ln(x)+x-2=0, sin(x)-0.5=0.
  • Equations are parsed by a built-in recursive-descent parser; eval() is never used.
