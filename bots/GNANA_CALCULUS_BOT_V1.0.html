Quick Tips

  • Enter functions using standard notation: x^2 + 3*x + sin(x), exp(x), ln(x), sqrt(x).
  • Use * for multiplication. Parentheses are recommended for clarity.
  • Results distinguish exact symbolic answers from numerical approximations.
  • Unsupported cases show clear messages — never invented steps.
