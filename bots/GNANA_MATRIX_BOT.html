Welcome to the Interactive Matrix Laboratory

GNANA MATRIX BOT V1.0 is a fully offline, browser-based tool for Engineering Mathematics. All computations run locally using Math.js. No login, no API keys, no data leaves your device.

Matrix Input Lab
Create, paste, randomise or load sample matrices A and B.
Basic Operations
Add, subtract, multiply, transpose, power, norms, equality.
Determinant & Inverse
det, inverse, adjoint, cofactor with verification.
Rank & Reduction
Rank, REF, RREF with step-by-step row operations.
Linear Systems
Solve AX = B by several classical methods.
Eigenvalues
λ, eigenvectors, characteristic polynomial, verification.
Decomposition
LU, QR, Cholesky, SVD (where supported).
Visualization
Interactive heatmaps of matrix entries.
Tolerance used for numerical comparisons: ε = 10−10. Floating-point results may differ slightly from exact symbolic values. Always verify critical calculations by hand or with independent software.
