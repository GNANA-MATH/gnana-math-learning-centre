How it works

  1. Enter or dictate a question.
  2. The page searches couplets and commentary fields.
  3. Relevant source text is displayed with the Kural number.
  4. Use Read aloud if a Tamil voice is available.
This is keyword retrieval, not a full language model. It does not generate explanations absent from the loaded dataset.

🔒 Offline use: what to know

Keyword search works locally after opening this page. Browser speech recognition commonly relies on an online service and may not work offline. Speech output depends on installed/browser voices. Fully offline voice input and Tamil TTS require local models; a single HTML file cannot reliably include them.
